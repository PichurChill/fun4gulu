# 3D 模型资源来源说明

本目录内所有 3D 模型仅用于个人非商业学习与家庭娱乐体验。

- **迪迦奥特曼 (`tiga.glb`)**：改编自 BlendSwap 社区创作者 Extrazhang 的粉丝作品 *Ultraman Tiga*（CC-BY-NC，非商用），经 `adoin/IAmUltraman` 导出为带 52 根骨骼与 PBR 贴图的网页 GLB 资源。
- **戴拿闪亮型与泽塔原生型（`dyna.glb`、`zeta.glb`）**：沿用上述 Extrazhang 作品的人体基础网格与骨架，重新设计头盔、胸灯和战衣配色，同样遵循原作非商用条件。
- **赛罗奥特曼 (`zero.glb`)**：改编自 GitHub 开源奥特曼粉丝游戏 `zhangjianbang-nb/ultraman-zero-lightfall` 仓库中的 `sailuo_rig.glb`（Bip001 骨架、带手指绑定），同属非商用粉丝作品。
- **经典怪兽 (`baltan.glb`, `ganq.glb`, `zetton.glb`, `gomora-mecha.glb`, `gatanothor.glb`)**：源自公开社区非商用粉丝 MMD / Sketchfab 模型转换产物（源自 `adoin/IAmUltraman` 开源仓库）。
- **城市建筑 (`city/*.glb`, `city/Textures/colormap.png`)**：Kenney City Kit Commercial（CC0 公共领域许可，见 `city/License.txt`）。

## 战场摄影资源

战场使用 Poly Haven 的 CC0 实景全景与地表扫描素材，已转换为随游戏分发的 WebP。

- 海港采用 [Simon's Town Harbour](https://polyhaven.com/a/simons_town_harbour)。
- 都市采用 [Dresden Square](https://polyhaven.com/a/dresden_square)。
- 山区采用 [Alps Field](https://polyhaven.com/a/alps_field)。
- 火山口的远景取自 [Quarry 01](https://polyhaven.com/a/quarry_01)，岩壁使用 [Aerial Rocks 02](https://polyhaven.com/a/aerial_rocks_02) 的颜色与法线纹理。地形、熔流与光照由游戏绘制。
- 码头的近景铺装采用 [Asphalt 04](https://polyhaven.com/a/asphalt_04)。
